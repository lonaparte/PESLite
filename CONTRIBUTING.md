# Contributing to PESLite

You are welcome to contribute to PESLite. Please keep changes focused, follow the existing project
style, and run the relevant tests before opening a pull request.

## Contributor License Agreement

Contributions to PESLite require acceptance of the
[PESLite Contributor License Agreement](CLA-v1.0.md).

If you have not accepted it before, the CLA bot will guide you automatically when you open a pull
request.
